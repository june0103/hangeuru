# 2026-11-18-logo

- 대상: 서비스 이름 "커리어캠프"의 로고, 헤더 브랜드 마크, 파비콘과 홈 화면 아이콘
- 만든 사람: Claude Code 초안(디자이너 시안 아님). 캠프 배너의 "굵은 글자 위에 걸친 유리 큐브" 분위기를 참고해 새로 그렸다. 캠프 공식 로고를 옮기지 않았다
- 그린 범위: 라이트·다크, 모바일·데스크톱 공용(SVG)

| 파일 | 쓰는 곳 |
| --- | --- |
| `logo-on-dark.svg` | 어두운 바탕에 올리는 큰 로고(CAREER CAMP + 유리 큐브) |
| `logo-on-light.svg` | 밝은 바탕에 올리는 큰 로고 |
| `mark.svg` | 헤더 브랜드 마크(배경 투명, 24px 안팎). 옆에 "커리어캠프" 글자를 붙인다 |
| `icon.svg` | 파비콘, 홈 화면 아이콘(192·512px, 어두운 둥근 정사각형) |
| `preview.html` | 위 파일을 바탕별로 나란히 본 미리보기 |
| `mklogo.py` | 위 SVG를 만드는 스크립트. 크기·색을 바꿀 때 고쳐서 다시 돌린다 |

남은 질문
- 큰 로고의 글자는 SVG `text`라 Pretendard가 없는 곳(이미지 뷰어, 다른 앱)에서는 기본 글꼴로 보인다. 확정되면 글자를 윤곽선(path)으로 바꾼다
