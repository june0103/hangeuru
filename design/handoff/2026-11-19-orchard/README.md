# 2026-11-19-orchard

보드(현재 화면 보드) Version 34를 1차 완성본으로 올린다. 앱 코드에는 이 폴더를 기준으로 옮긴다.

- 대상 화면: 스플래시(새로), 로그인, 가입, 씨앗 고르기(새로), 홈(다섯 상태와 20일 이후), 20일 열매 화면(새로), 내 설정, 수확 카드, 캘린더(11월·12월), 모두의 과수원, 없는 페이지
- 아티팩트 링크: https://claude.ai/artifact/8aFuZxzfKVrX7XDU5wM7TE
- 그린 범위: 라이트·다크, 모바일 360px(360 × 780, 가장 작은 기준)·데스크톱 1280 × 800
- 만든 방법: develop 코드를 가짜 구성원 9명(오늘 = 2026-12-17)으로 띄워 서버 HTML을 떠내고, 그 위에 `assets/orchard.js`가 디자인을 입힌다. `splash`, `seeds`, `fruiting`, `home-fruit`는 앱에 없던 화면이라 새로 만든 것이다
- 여는 법: `screens/*.html`을 로컬 서버로 연다(파일로 바로 열면 `../assets/orchard.js`와 three.js CDN을 읽지 못할 수 있다). 주소 끝에 `?theme=light`나 `?theme=dark`, 움직임 없이 보려면 `&mode=static`
- 글꼴: 파일에 넣지 않고 Pretendard CDN 스타일시트를 쓴다

## 바뀐 점

공통
- 배경: 초점이 나간 꽃이 물결처럼 떠다니는 셰이더. 몽타주 atomic 색만 쓰고 라이트·다크 팔레트가 따로 있다. 내 씨앗에 따라 꽃 색 계열이 바뀐다
- 패널: 흰 바탕 대신 유리(반투명 + 뒤 흐림 + 위쪽 빛). 헤더는 띠 없이 배경에 녹아든다
- 헤더: 탭 셋을 가운데에(탭 모양은 몽타주 탭 그대로), 오른쪽에 화면 테마 전환(Light·Dark·Auto)과 이름. 로그아웃은 내 설정 맨 아래로 옮겼다
- 모바일: 아래 탭은 화면에서 띄운 유리 알약. 프로필 아이콘 24px(누르는 영역 44px)
- 파란 주 버튼: 올리면 살짝 비치며 수면이 찰랑인다
- 화면 이름 "내 나무" → "내 씨앗"

온보딩
- 스플래시: 스크롤(모바일은 화면을 누름)을 따라 세 장면. 모바일은 가운데 아래 "시작하기 >" 유리 버튼과 위의 "건너뛰기". 한 번 로그인하면 다시 나오지 않는다
- 씨앗 고르기: 가입 폼에서 빼고 가입 뒤 별도 화면. 큰 과일 하나가 주인공이고 화살표·작은 과일·방향키로 바꾼다. 잡고 끌면 돌고 누르면 잠깐 움츠린다. 심기를 누르면 씨앗이 흙에 떨어지고 새싹이 올라온다
- 자란 나무는 미리 보여 주지 않는다

홈
- 데스크톱(992px 이상)은 세 칸 두 줄로 스크롤 없이 한 화면: 왼쪽 오늘·이번 주, 가운데 내 씨앗, 오른쪽 오늘 그라운드·배지
- 나무: 씨앗마다 다른 실사풍 3D 나무 네 종. 톡 치거나 잡고 흔들면 살짝(약 6도까지) 흔들리고 잎이 떨어진다
- 내 씨앗 패널: "단계"라는 말 없이 지금 모습을 말하듯 쓴 한 줄과, 작은 글씨의 "출근 N일 · …". 씨앗 칩을 누르면 툴팁. 레벨 표시(겹친 도형, 색 다섯 가지)와 같은 간격의 성장 막대
- 배지 패널(새로): 첫 출근, 주간 목표, N주 연속, 10일 출근, 첫 수확
- 이번 주: 보라색 대신 배지와 같은 파랑 유리
- 모바일 출근하기 버튼은 화면 아래 고정이 아니라 오늘 패널 안
- 출근: 열매 전에는 물뿌리개가 물을 준다. 20일이 되면 20일 열매 화면으로 가고, 닫으면 홈에서 계속 출근한다. 20일 뒤에는 출근할 때마다 열매가 하나씩 는다

그 밖
- 20일 열매 화면: "내 씨앗이 / OO나무로 열렸어요", "고생했어요", 닫기·다시 보기
- 수확 카드: 유리 카드, 3D 과일, 초록 막대 하나와 퍼센트("출근일 27일 중 N일"), 버튼은 닫기·저장하기. 창도 작은 유리 창
- 캘린더: 제목을 화면에서 빼고 연·월을 가운데로, 출근 표시는 8px 원, 모바일 기록 표는 가로 스크롤 없이 네 칸

## 확인하지 못한 것

- 실제 휴대폰에서의 터치와 모션의 부드러움, 오래된 기기에서의 성능
- 게시된 보드 안에서 수확 카드 "저장하기"가 실제로 파일을 내려받는지
- 복숭아나무의 열매 맺힌 끝 모습(사과, 귤, 커피는 확인)
- 열매 맺히는 장면과 홈 패널 안에서 빛줄기가 끊기지 않는지
- 이번 주 패널의 다크 모습
- 1024 × 640에서는 데스크톱 홈이 4px 넘친다
