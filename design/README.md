# 디자인 작업물 올리는 법

화면 모양은 이 폴더의 가장 최근 시안이 기준이다. 규칙, 데이터, 서버 동작은 `docs/spec.md`가 기준이다.

## 올리는 규칙

- 한 번 올릴 때마다 `design/handoff/` 아래에 폴더를 하나 만든다. 이름은 `YYYY-MM-DD-주제`다. 예: `2026-11-25-home`
- 시안은 Claude 아티팩트로 만든 HTML 파일을 내려받아 올린다. 파일 하나에 화면 하나나 흐름 하나를 담고, 이름은 화면 이름으로 한다. 예: `home.html`
- 폴더 안 `README.md`에 대상 화면, 바뀐 점, 아티팩트 링크를 적는다. 라이트·다크, 모바일·데스크톱 중 무엇을 그렸는지도 적는다
- 글꼴이나 큰 이미지를 HTML 안에 넣지 않는다. 파일이 커지면 에이전트가 읽기 어렵다
- 이미 올린 폴더는 고치지 않는다. 바뀌면 새 날짜 폴더를 만든다

## 폴더

| 경로 | 내용 |
| --- | --- |
| `reference/prototype.html` | 기획 단계의 예시 사이트. 고치지 않는다 |
| `handoff/YYYY-MM-DD-주제/` | 디자이너가 올린 작업물 한 묶음 |

## README.md 예시

```
# 2026-11-25-home

- 대상 화면: 홈
- 바뀐 점: 내 나무 패널의 그림과 성장 트랙
- 아티팩트 링크: https://claude.ai/artifact/...
- 그린 범위: 라이트, 모바일·데스크톱
```
